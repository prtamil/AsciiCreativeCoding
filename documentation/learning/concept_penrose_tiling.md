# Concept — `penrose_tiling.c`: Robinson-Triangle Deflation

(Distinct from the older `concept_penrose.md`, which covers the De Bruijn pentagrid demo. This file is the substitution / deflation variant.)

## Core Idea

To make an aperiodic tiling, take ONE tile and replace every copy of it with a **SMALLER ARRANGEMENT OF THE SAME TILES**. Repeat. Each round multiplies the number of tiles by the golden ratio `φ`; the shapes get finer and finer, but the SUBSTITUTION RULE is fixed. After N rounds the tiling looks complex, irregular, and non-repeating — yet it was generated by a single deterministic deflation rule. **That is Penrose: complexity from inflation.**

---

## The Mental Model

Imagine a piece of putty in the shape of an arrowhead. Cut it into two smaller arrowheads using a single specific cut. Now you have two pieces of putty, both arrowheads, in the shape configuration the cut prescribes. Cut each of those by the same rule. After enough rounds the original arrowhead has become a fractal-looking mosaic of tiny arrowheads.

Penrose's brilliance was finding an arrowhead — actually two arrowheads, the **acute** and the **obtuse Robinson triangle** — and a pair of cutting rules where the resulting mosaic is APERIODIC: no matter how big the patch you cut, you cannot translate it onto itself. Yet the global structure has perfect 5-fold rotational symmetry around the seed point. The hallmark of a quasicrystal.

---

## Algorithm in Steps

1. **SEED.** Place a few triangles in a known starting configuration. The classic "star" seed uses 10 acute triangles, all with their 36° apex at a common centre, alternating chirality so the deflation rules match across boundaries.

2. **DEFLATE one round:**
   For every triangle T in the current buffer:
   - if T is ACUTE: emit `(acute_child, obtuse_child)` per the rule.
   - if T is OBTUSE: emit `(obtuse, obtuse, acute)` per the rule.
   Swap buffers; the new buffer is now the active tiling.

3. **REPEAT step 2 K times.** Triangle count grows by factor `~φ` each round.

4. **RENDER each triangle to the screen** via Bresenham line drawing for its 3 edges; choose a colour from the active theme based on triangle type (acute vs obtuse) and direction-glyph from edge slope.

5. **ANIMATE** by overlaying a slow fBm brightness field that modulates per-cell `A_DIM`/`A_NORMAL`/`A_BOLD` without changing the underlying tiling.

## Key Formulas

**Golden ratio:**
```
φ      = (1 + √5) / 2 ≈ 1.618033988749…
1/φ    = φ - 1
```

**Acute triangle deflation** (apex A is the 36° vertex):
```
P = A + (B - A) / φ
→  ACUTE (apex C, base P, B)
   OBTUSE (apex P, base C, A)
```

**Obtuse triangle deflation** (apex A is the 108° vertex):
```
Q = B + (A - B) / φ
R = B + (C - B) / φ
→  OBTUSE (apex R, base C, A)
   OBTUSE (apex Q, base R, B)
   ACUTE  (apex R, base Q, A)
```

**STAR seed** (10 acutes radiating from origin, alternating chirality):
```
for i = 0..9:
  θ_a   = 2π·i / 10
  θ_b   = 2π·(i+1) / 10
  v_a   = (cos θ_a, sin θ_a)
  v_b   = (cos θ_b, sin θ_b)
  if i even:  triangle (acute, origin, v_a, v_b)
  else:       triangle (acute, origin, v_b, v_a)   [chirality flip]
```

**Bresenham line** from `(x0, y0)` to `(x1, y1)` — integer-only:
```
dx = |x1 - x0|;  sx = sign(x1 - x0)
dy = -|y1 - y0|; sy = sign(y1 - y0)
err = dx + dy
each step:
  plot(x, y)
  e2 = 2·err
  if e2 ≥ dy: err += dy; x += sx
  if e2 ≤ dx: err += dx; y += sy
until (x, y) == (x1, y1)
```

**Edge-direction glyph:**
```
|dx| ≥ 2·|dy|         → '-'
|dy| ≥ 2·|dx|         → '|'
sign(dx) == sign(dy)  → '\\'
else                  → '/'
```

## Robinson Triangles

Two triangle types from Penrose's P3 tiling:

| Type     | Angles            | Side ratios | Half of            |
|----------|-------------------|-------------|--------------------|
| ACUTE    | 36° / 72° / 72°   | 1 : φ : φ   | thin rhombus       |
| OBTUSE   | 108° / 36° / 36°  | 1 : 1 : φ   | thick rhombus      |

After K=5 deflations from the STAR seed: ~900 triangles. K=6: ~2 300.

## Edge Cases and Pitfalls

- **TRIANGLE BUFFER OVERFLOW.** Each iteration can multiply by up to 3× (obtuse → 3 children). With `MAX_TRIANGLES=4096` and a STAR seed (10), K=7 would overflow. The deflation function checks bounds and stops emitting once full — visually, the tiling becomes incomplete (some triangles missing) rather than crashing. Cap K at 6 for the STAR seed.

- **CHIRALITY IN THE SEED.** The STAR seed alternates orientation (the `(i & 1)` flip) so the deflation rule produces a valid tiling at every triangle boundary. Without alternation, child triangles from neighbouring seed triangles would not align edge-to-edge and the tiling would have visible gaps or overlaps after deflation.

- **ASPECT RATIO.** Triangle vertices are in unit-circle coords; we scale to screen by multiplying x by `scale` and y by `scale / ASPECT_Y_F` so the tiling renders square (not horizontally squashed). Without this correction the 5-fold symmetry would look like a flattened ellipse.

- **SHARED EDGES DRAWN TWICE.** Adjacent triangles share their "long" edge (the rhombus's diagonal). The renderer draws ALL edges of all triangles, so each shared edge is drawn twice in the same colour. Visually identical to drawing once; the overhead is negligible.

- **BRESENHAM AT ENDPOINTS.** Same edge endpoint drawn from two triangles → that cell is written multiple times. Last write wins for colour/attr. Since adjacent triangles have different colours (acute vs obtuse), corner cells take whichever colour was rendered last. Acceptable visual artifact.

- **FLOAT-TO-INT ROUNDING.** Vertices are floats; mvaddch needs ints. Truncating with `(int)` introduces a 1-cell jitter at certain angles. Use `lroundf` or `floorf + 0.5` for cleaner alignment if you notice artifacts. Default `(int)` cast is OK at 240×80.

## How to Verify

- **PAUSE** (space). The brightness wave freezes; the static tiling is unchanged. Resume: drift continues from where it stopped.

- Press **`r`**. The flash fires and the tiling rotates / re-orients around the centre.

- **STAR** pattern. Look at the centre — you should see 10 triangles meeting at one point, creating perfect 5-fold rotational symmetry. After K=5 deflations every original triangle has been replaced with ~90 smaller ones.

- **THIN** pattern. A single thin rhombus (long thin shape, vertical) fills the centre, deflated to its smaller children. Almost all visible triangles are acute (a property of thin-rhombus deflation).

- **THICK** pattern. A thick rhombus (almost square) fills the centre. Visible triangles are mostly obtuse.

- **Glyph cycle (g)**. The triangle layout doesn't change; only the rendering does. EDGES shows pure line art. CENTERS shows a "pointillist" version with one dot per triangle. BOTH overlays.

- **Theme cycle (t)**. Colours for acute vs obtuse should be visibly distinct in every theme.
